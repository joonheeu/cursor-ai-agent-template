## 📊 우선순위 매트릭스

```
                중요도 높음
                    ↑
          P0 필수   |  P1 권장
         (포함)     | (포함 가능)
    ←───────────────┼───────────────→
         P2 선택   |  P3 제외
        (미포함)    | (미포함)
                    ↓
                중요도 낮음
```

### 우선순위 정의
- **P0 (필수)**: MVP 없이는 출시 불가, 핵심 가치 제공
- **P1 (권장)**: MVP에 포함하면 좋지만 필수는 아님
- **P2 (선택)**: 초기 버전에서 제외, 향후 추가 고려
- **P3 (제외)**: 당분간 계획 없음
